# BELDA TREE DOCTOR | versión 0.1
Aplicación web progresiva (PWA) independiente de ChatGPT para diagnóstico orientativo del arbolado urbano adulto. Aplicación y servidor incluidos; todavía no desplegados en internet. No requiere instalar un GPT. Solo especie y 1–4 fotografías. Requiere internet y clave API de OpenAI. No compartir la clave con el equipo ni introducirla en el navegador.

## Prueba rápida en Windows
1. Descomprime el ZIP. Instala Python 3.12 o posterior desde https://www.python.org/downloads/ (si no está disponible).
2. Crea una clave en https://platform.openai.com/api-keys y configura el pago en https://platform.openai.com/settings/organization/billing/overview. La API se factura aparte de ChatGPT. Revisa límites de uso y coste; el modelo predeterminado es gpt-6-astra, de alta capacidad pero de mayor precio. Puedes cambiar OPENAI_MODEL a un modelo compatible con imágenes y web search; consulta https://developers.openai.com/api/docs/models.
3. Ejecuta INICIO_WINDOWS.bat. Introduce la clave y una contraseña propia robusta (se mantienen en la sesión del servidor, no se escriben en archivos). Abre http://localhost:8000. Introduce en la web únicamente la contraseña elegida. El proceso debe estar funcionando mientras se usa.
4. El móvil y el PC pueden probar vía la misma red Wi-Fi: consulta `ipconfig` y escribe `http://IP_DEL_PC:8000` en el móvil; puede ser necesario permitir el puerto en el cortafuegos de la red privada. NO expongas este servidor de desarrollo a internet; HTTP no cifra credenciales ni fotos. Usa esta prueba únicamente en una red de confianza. La instalación PWA y el funcionamiento de cámara desde navegador pueden requerir HTTPS; para uso en campo sigue el siguiente apartado.

## Uso en campo desde cualquier red
Publica el directorio en un servicio de alojamiento web que admita Docker y HTTPS (por ejemplo Render, Railway, o un servidor de empresa administrado). El Dockerfile ya contiene el comando de arranque. En la configuración privada de variables de entorno del alojamiento, establece `OPENAI_API_KEY`, `APP_PASSWORD` (contraseña robusta y distinta de la clave API) y opcionalmente `OPENAI_MODEL`. Usa el puerto `PORT` que asigne el alojamiento. No subas archivos .env ni claves al repositorio. El código y las láminas deben quedar en un repositorio privado si la documentación no es de libre distribución. Configura HTTPS y un tiempo de espera compatible con peticiones largas (> 2 min); el plan de alojamiento puede imponer límites. Pide a informática que aplique control de acceso adicional, límites de gasto y protección de datos antes de abrirlo a todo el equipo. El prototipo protege la API con una contraseña común y limita a 2 análisis simultáneos, no implementa usuarios individuales ni protección de fuerza bruta exhaustiva.

Abre la URL HTTPS del alojamiento en Android (Chrome > menú > Instalar aplicación/Añadir a pantalla de inicio) o iOS/iPadOS (Safari > Compartir > Añadir a pantalla de inicio). El diagnóstico requiere conexión. La PWA no es una aplicación nativa publicada en Google Play/App Store.

## Qué hace
- Primera consulta multimodal: observa la foto y selecciona hasta 5 fichas de un índice temático de 42 entradas. Busca también textos relevantes entre 543 páginas con texto de los 5 documentos originales.
- Segunda consulta: envía las fotos del caso, texto de las fichas seleccionadas y hasta dos láminas por ficha (de 139 páginas visuales del anexo original). El modelo compara dichas imágenes. La lámina mostrada en la respuesta corresponde a la evidencia enviada, no necesariamente a una identificación cierta.
- Búsqueda web opcional activada por defecto: solicita texto e imágenes de fuentes fiables si el modelo/API admite esa función; si la API rechaza opciones de imagen, intenta búsqueda textual y avisa. Los resultados externos pueden no estar disponibles visualmente para el modelo y no deben tratarse como comparación realizada si no lo están. Las citas URL se muestran y se enlazan. El modelo puede decidir no buscar si no procede.
- Devuelve diagnóstico diferencial, confianza cualitativa, síntomas, implicaciones sobre estabilidad, prioridad, comprobaciones y fuentes. El navegador permite consultar las láminas locales y descargar el informe como TXT. Almacena hasta 25 informes en el navegador (sin fotografías). Borrar historial elimina esos informes del dispositivo. El servidor no guarda las fotos de campo por diseño; se remiten a la API de OpenAI para procesarlas, con `store:false`; esto no equivale a una garantía de retención cero por parte del proveedor. Evita datos personales y revisa condiciones de tratamiento antes del uso profesional.

## Comprobación y mantenimiento
La estructura, archivos, rutas, acceso, y comportamiento con una API simulada se han comprobado localmente. No se ha probado con una clave real ni publicado en un alojamiento. Para validar el diagnóstico, usar casos de campo confirmados por técnico/laboratorio y revisar errores por especie. La app no certifica estabilidad ni sustituye una inspección presencial. Los errores de API aparecen en la pantalla; no se inventa un diagnóstico cuando falta conexión, clave o saldo.
